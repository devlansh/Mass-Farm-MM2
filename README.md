# Mass Farm MM2
Murder Mystery 2 autofarm for a large amount of accounts.

> ⚠️ **Disclaimer:** Use at your own risk. Roblox may ban accounts for automation.

## 🚀 Quick start

Run this in your executor:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/devlansh/Mass-Farm-MM2/refs/heads/main/main.lua", true))()
```

## ✨ Features

- Simple GUI — convenient when many tabs are open
- Farm strategy focused on the closest coin
- Host system — all accounts on one device join the same server

## 📋 Requirements

Your executor must support the following UNC methods:

`isfolder`, `makefolder`, `isfile`, `readfile`, `writefile`, `setclipboard`

> A runtime check for these methods will be added later.
